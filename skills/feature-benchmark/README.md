# feature-benchmark

**Le problème :** un benchmark qui liste les fonctionnalités des concurrents ne dit pas quoi construire.

**Ce que fait le skill :** il découpe d'abord le problème en moments où l'utilisateur peut décrocher, puis cherche une douzaine de références en trois familles (concurrents directs, indirects, autres secteurs), chacune vérifiée par une source. La synthèse classe les mécanismes par coût de mise en œuvre et se termine par les prochains tests à mener.

**Exemple (fictif) :**
> « Benchmark : comment les autres produits réduisent les rendez-vous non honorés ? Produit : Atelier Vélo, en France. »

Références attendues : d'autres plateformes de réservation, mais aussi la santé (rappels de consultation) ou la restauration (empreinte bancaire).

**Livrables :** un document Markdown et une page HTML à onglets. Le skill est écrit en anglais ; il demande la langue du livrable.
