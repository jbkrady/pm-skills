# interview-guide-interactif

**Le problème :** pendant un entretien, on jongle entre un document de questions, des notes et un chronomètre. Les notes de chaque entretien finissent éparpillées.

**Ce que fait le skill :** à partir de questions déjà validées, il propose d'abord la structure (personas, blocs, objectifs de recherche), puis construit une page de terrain : cases à cocher, notes par bloc, sauvegarde de chaque entretien et export Markdown.

**Exemple (fictif) :**
> « Voici mes 18 questions pour les cyclistes et les ateliers d'Atelier Vélo. Fais-moi la grille d'entretien. »

Le skill répond par la structure en texte (2 fiches, 5 blocs, 3 objectifs de recherche) et attend la validation avant d'écrire la page.

**À savoir :** les données restent dans le navigateur de chacun ; l'export Markdown sert à les rassembler dans l'outil de l'équipe.
